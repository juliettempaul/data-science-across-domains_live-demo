## Smile Detection CNN — live classroom demo

A small, self-contained teaching demo: a convolutional neural network that classifies face images as
smiling or not smiling, trained on a small sample (380 images) of the
[GENKI-4K dataset](https://www.kaggle.com/datasets/talhasar/genki4k).

This repo exists to power a **live, in-browser, no-account-needed** version of the demo via
[Binder](https://mybinder.org) — click the badge below (once added) to launch it. Training and
evaluation finish in a few minutes on Binder's free CPU-only environment.

This is a trimmed companion repo for classroom use, not the full project — a small sample dataset and
just the code needed for this demo.
